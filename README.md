# Trader Library Video Companion Releases

This public repository contains downloadable **binary release assets only** for the Admin-only Trader Library Video Dubbing workspace.

- The private Trader Library application source code is not published here.
- User video, audio, transcript, Raw Project, and export files are never uploaded here.
- Processing stays on the Admin PC through the loopback Companion and bundled FFmpeg.
- Release assets include a SHA-256 checksum metadata file.
- The current Windows package is an unsigned Admin beta and may trigger Windows SmartScreen.

Official production origins allowed by the package:

- `https://trader-library.com`
- `https://www.trader-library.com`

Download packages from the repository **Releases** page. Verify the SHA-256 shown in the release before installation.
